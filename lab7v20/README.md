## Контрольні питання

1. **Які винятки найчастіше виникають при роботі з файлами та мережею?**  
   **Файли:** `FileNotFoundException`, `IOException`, `UnauthorizedAccessException`  
   **Мережа:** `HttpRequestException`, `SocketException`, `TimeoutException`

2. **У чому принцип роботи патерну Retry? Коли його застосовують?**  
   Патерн Retry повторює операцію після помилки кілька разів із затримкою.  
   Використовується при тимчасових збоях: нестабільна мережа, зайнятий файл, короткі збої сервера.

3. **Як зробити експоненційну затримку між спробами?**  
   Формула:  
delay = initialDelay * 2^(attempt - 1)


4. **Для чого потрібен делегат `shouldRetry`?**  
Він визначає, для яких винятків дозволено повторювати спробу.  
Наприклад: `IOException`, `HttpRequestException`.
